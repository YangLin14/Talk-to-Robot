# Talk-to-Robot

Studying when one-shot LLM language grounding is enough for goal-conditioned robotic manipulation. SAC+HER policy on FetchPush-v3, Gemini 2.5 Flash frontend, regex baseline for grounding-necessity ablation.

## Intro

Humans don't speak in coordinates. This project studies the simplest reliable way to bridge natural-language instructions and learned robotic controllers, in simulation. We compare a decoupled pipeline (LLM queried once per task) against a regex baseline across instruction tiers from literal to abstract, on the FetchPush-v3 MuJoCo benchmark. UCSD CSE 190 Spring 2026.
